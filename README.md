## Project 2 air pollution patterns at RDU airport

This project cleans daily air pollution measurements and compares CO, PM2.5, and O3 patterns across months and years. It provides an exploratory exposure summary for a proposed study of air pollution and sickle cell disease in Durham County, North Carolina.

### Data source

The three CSV files were supplied with the BIOSTAT 721 Project 2 assignment and contain EPA monitor measurements from RDU airport for 2018, 2019, and January-April 2020. CO and O3 are recorded in ppm, and PM2.5 is recorded in ug/m3 LC.

### How to reproduce

1. Clone or download this repository and open `BIOSTAT721.Rproj` in RStudio.
2. Install the required packages once:

   ```r
   install.packages(c("ggplot2", "knitr", "rmarkdown"))
   ```

3. From the project root, render the report:

   ```r
   rmarkdown::render("Project2/Project2.Rmd")
   ```

   Alternatively, open `Project2/Project2.Rmd` and select **Knit to Word**. RStudio includes Pandoc, which is needed to create the Word file. Rendering regenerates the Word and Markdown reports, both plots, and the CSV outputs. The code was run with R 4.3.3.

### Cleaning and summaries

`clean_air_quality(file_path, ozone_units = "ppm")` removes identical rows, sets negative measurements to zero, and averages measurements within each date, in that order. Missing values are excluded from each pollutant's average; dates with no measurements remain `NA`. Four missing dates within the 2018 calendar are included as rows with missing concentrations. To return O3 in ppb, use `ozone_units = "ppb"`.

The annual tables give daily minima and maxima to three decimal places. The CO and O3 plot pools daily observations within each calendar month across years and uses mean +/- 1.96 x SD / sqrt(n) for its 95% confidence intervals. Separate panels allow different y-axis scales. The PM2.5 plot compares monthly means by year; the 2020 line stops in April.
